# Engineering boundaries

Strict Python/TypeScript; validate commands and card/tool outputs. Focused functions, early returns, one modular backend. FastAPI owns canonical writes; Server Actions cannot bypass scope/version/idempotency. No silent stock deduction or numeric defaults for unknowns. Typed errors preserve drafts; paid operations bounded. Never log private household inputs, receipts or memory.
