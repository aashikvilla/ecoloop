PROMPT 00 — FOUNDATION + S00 HOME
Design a consumer-facing, responsive WEB app called EcoLoop AI (Next.js/optional PWA, NOT native). It helps an everyday individual or optional family use existing food, decide what to cook, check before shopping and see genuinely recorded kitchen habits. Create a premium warm contemporary interface: porcelain #F7F8F4 background, deep forest #18382F, emerald #287256, pale mint #DDF2E6, subtle coral warnings, modern Plus Jakarta Sans/Inter typography, rounded 16–20px cards, elegant food photography, generous whitespace, accessible contrast. Use a 390x844 mobile-browser frame; support 1440px desktop responsive layout. Four primary navigation items Home/Kitchen/Ask/Shopping, compact household selector My Home, profile/settings. Privacy-first and no greenwashing. All data mock and marked demo where needed. GENERATE ONLY ONE INITIAL SCREEN, S00 populated HOME/TODAY: greeting Good evening; Tonight's dinner (four people expected, tomato–spinach rice, Plans changed? CTA); Needs attention (Spinach last checked 2 days ago, Review CTA — NOT fabricated expires tomorrow); quick actions Ask what to cook and Check before buying; small 'Kitchen progress' with 3 items marked used (recorded example) and 180g edible discarded (self-reported example), How we measure link. Elegant bottom nav with Home selected. DO NOT generate other pages; later prompts will add them to THIS SAME project. Save design tokens / DESIGN.md if available.
