# Architecture knowledge
16 October 2026 — current authority: [household specification](../planning/CURRENT_MVP_SPEC.md), sections 4–7. Household browser demo and secure FastAPI/Firestore groundwork are implemented. Cloud deployment and managed-service behavior remain unproved.

Planned: Next.js/App Hosting; FastAPI/Cloud Run canonical authority; real Gemini and one ADK orchestrator; managed Sessions and consented Memory Bank; preferred managed Runtime. Fallback needs concrete blocker and equivalent proof. Firestore owns confirmed facts/actions/outcomes; memory stores approved preferences. Five typed cards. Private owner-recorded sharing log; real community/commerce operations deferred.

Current implementation: Next.js 16.4.1, React, Tailwind v4; synthetic local store uses immutable external snapshots, runtime validation and browser persistence. It is deliberately separate from authenticated household data. Five fixed assistant card renderers validate backend-shaped envelopes and isolate malformed cards; their demo proposals cannot approve canonical actions. A separate `/account` route prepares Firebase session sign-in, authenticated Kitchen/Shop reads, owner-private history and explicitly reviewed Kitchen/Shopping commands. Commands default off until live acceptance and approval to enable them; a shared bounded allowlisted transport never automatically retries writes. Identity/household changes cancel requests and clear private state. Live connectivity remains unverified. FastAPI verifies Firebase identity plus explicit active household membership; scoped Firestore transactions include version checks, actor-bound idempotency and payload fingerprints. Owner-private share logs and activity APIs add atomic handover outcomes, scoped pagination and household-timezone expiry checks. Client Firestore/Storage rules deny access by default. Managed assistant returns an explicit unavailable response. See backend-foundation.md, the second-wave implementation notes and latest session for exact limitations.

The [old broad architecture](../archive/2026-10-15-pre-consumer-replan/planning/00_START_HERE.md) is archived. Do not revive operator lanes, dark cockpit, unsupported safety/carbon constants or fabricated benchmarks.


Frontend foundation: Tailwind CSS v4 `@theme` in `frontend/src/app/globals.css` is the single semantic design-token source. `frontend/src/components/ui/` contains shared primitives; `frontend/src/components/layout/` contains shared navigation/page shell. Build mobile-first from 360px. No frontend/backend unit tests; use evidence from allowed integration, security, accessibility and end-to-end checks instead.
