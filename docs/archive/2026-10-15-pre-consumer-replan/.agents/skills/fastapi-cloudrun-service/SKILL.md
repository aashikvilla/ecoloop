# FastAPI Cloud Run Service Skill

This skill provides step-by-step guidance for developing high-performance, asynchronous REST APIs with FastAPI and deploying them onto Google Cloud Run.

## Key Capabilities
- **FastAPI 0.115+ & Pydantic v2**: Type-safe request/response validation, automatic OpenAPI specs.
- **Firebase Token Verification**: Server-side Bearer token authentication via `firebase-admin`.
- **Cloud Run Optimization**: Stateless container architecture, `$PORT` environment variable binding, graceful shutdown.
- **Modular Architecture**: Layered `core/` (config & security), `schemas/` (Pydantic contracts), `api/v1/endpoints/` (routes), and `services/` (domain logic).

## 2. Core Implementation Patterns

### A. Environment Configuration (`app/core/config.py`)
Always use `pydantic-settings` to parse environment variables safely with defaults:
```python
from typing import List, Union
from pydantic import AnyHttpUrl, field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    PROJECT_NAME: str = "EcoLoop API"
    API_V1_STR: str = "/api/v1"
    PORT: int = 8000
    GCP_PROJECT_ID: str = "project-7eb2c8c6-27da-46d0-827"
    FIREBASE_CREDENTIALS_PATH: str = ""
    BACKEND_CORS_ORIGINS: List[str] = [
        "http://localhost:3000",
        "https://ecoloop.web.app",
        "https://ecoloop.firebaseapp.com",
    ]

    @field_validator("BACKEND_CORS_ORIGINS", mode="before")
    @classmethod
    def assemble_cors(cls, v: Union[str, List[str]]) -> List[str]:
        if isinstance(v, str) and not v.startswith("["):
            return [i.strip() for i in v.split(",")]
        return v if isinstance(v, list) else []

    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

settings = Settings()
```

### B. Firebase Authentication Guard (`app/core/security.py`)
Verify JWT tokens generated by Firebase Auth:
```python
import firebase_admin
from firebase_admin import auth as firebase_auth, credentials
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

security_scheme = HTTPBearer(auto_error=False)

def get_current_user(token: HTTPAuthorizationCredentials = Depends(security_scheme)):
    if not token:
        # In demo mode, allow mock user if explicit header or environment
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Missing Bearer token",
            headers={"WWW-Authenticate": "Bearer"},
        )
    try:
        decoded_token = firebase_auth.verify_id_token(token.credentials)
        return {
            "uid": decoded_token.get("uid"),
            "email": decoded_token.get("email"),
            "tenant_id": decoded_token.get("tenant_id", "default-tenant"),
            "roles": decoded_token.get("roles", ["household_member"]),
        }
    except Exception as exc:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail=f"Invalid authentication token: {str(exc)}",
            headers={"WWW-Authenticate": "Bearer"},
        )
```

## 3. Cloud Run Deployment Procedures

Refer to [Cloud Run Docker Guide](./references/cloudrun_docker.md) for complete Dockerfile and deployment commands.

Quick deployment command:
```bash
gcloud run deploy ecoloop-backend \
  --source . \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars ENVIRONMENT=production,GCP_PROJECT_ID=project-7eb2c8c6-27da-46d0-827 \
  --memory 1Gi \
  --cpu 1
```
