## Concrete defects and limits

1. **Blocking correctness defect, already observed:** numeric Pydantic literals in the nested assistant output schema cannot be transformed by the current ADK/GenAI schema path. It prevents the request reaching Gemini. The source makes this likely reproducible (`Literal[1]` in `AssistantEnvelope`, passed via `AgentOutput` to `LlmAgent`); the latest session records the observed failure. Fix is owned by `codex/real-household-agent`; obtain its handoff/review before touching that module, then verify a successful provider response separately.
2. **Selected-context truncation:** `_kitchen_query` searches only the newest 200 observations before filtering the requested item IDs ([household.py](../../backend/app/agents/household.py#L235)). A selected older item beyond that window silently becomes absent context. Prefer direct scoped document reads for explicit IDs, while retaining a bounded query for unselected context.
3. No additional auth bypass was established in this source audit. API reads/commands use a `Principal` dependency, and the identity resolver verifies the selected household membership ([identity.py](../../backend/app/core/identity.py#L64)). This is source inspection, not a new hostile/security exercise.
