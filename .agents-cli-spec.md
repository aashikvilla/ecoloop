# EcoLoop ADK agent spec

## Purpose

One authenticated household assistant helps an owner review confirmed pantry facts, active shopping intent and saved meal plans, then returns one of EcoLoop's fixed typed proposal cards. The owner explicitly approves every canonical change through the existing FastAPI command API.

## Existing implementation to preserve

- Keep `backend/app/agents/household.py` as the sole product orchestrator. Its API caller supplies a Firebase-verified user and active household; tools recheck membership and remain read-only.
- Firestore remains authoritative for household facts, plans, outcomes and owner-private preferences.
- ADK's temporary in-process session service remains the local fallback.
- Never send household chat transcripts or arbitrary household facts to long-term memory.

## Managed services

- Preferred production session service: Agent Engine managed Sessions, scoped by the verified Firebase UID and household, with foreign-session denial.
- Memory: Agent Engine Memory Bank may receive only an explicitly approved, owner-private preference. A preference correction replaces or deletes the prior provider memory; revoke/delete must remove it and report incomplete deletion honestly.
- Runtime: Agent Engine is the preferred managed ADK runtime. The existing FastAPI/Cloud Run API remains the identity, membership, validation and canonical mutation boundary.
- Cloud calls remain disabled unless a deployment is explicitly configured and passes the privacy, cost and acceptance gates in `docs/planning/AGENT_PLATFORM_PLAN.md`.

## Safety and cost boundaries

- No autonomous writes, arbitrary tool endpoints, memory from transcripts, fabricated safety or sustainability claims, or model-owned arithmetic/authorization.
- No cloud provisioning, model calls, or deployment during local implementation. Do not read real env files or store credentials in Git.
- Before paid services: verify billing-linked projects, credits, region, IAM, Secret Manager, budget alerts and service-specific spend controls. The observed ₹2,000 monthly Gemini API spend cap does not cap Agent Engine, Cloud Run, Storage or other services.

## Evaluation

Prepare synthetic, non-sensitive evaluation cases for household-scope isolation, read-only tools, schema-safe cards, consent boundaries and revocation. Run `agents-cli eval` only after an explicit per-run cost limit and managed runtime are available; first inspect the generated traces for privacy before expanding the dataset.
